# WAYFORALL
### AI-Powered Accessible Navigation for Wheelchair Users

## About the Project
WAYFORALL is an accessibility-focused navigation platform designed to help wheelchair users travel more independently and safely.

## Problem
Wheelchair users face difficulties navigating public spaces due to broken footpaths, missing ramps, stairs and blocked pathways.

## Our Solution
WAYFORALL provides accessible route planning, personalised navigation and community-based barrier reporting.

## Key Features
- Accessible route planning
- Barrier reporting through photographs
- Personalised accessibility preferences
- Community-verified accessibility information
- Voice navigation

## Technology Stack
- React
- Python Flask
- Firebase
- OpenStreetMap

## Setup Instructions

WAYFORALL is currently in the prototype development stage.

### Prerequisites
- Node.js and npm
- Python 3
- Firebase account
- Internet connection

### Setup Steps
1. Clone or download the project repository.
2. Install the required frontend dependencies.
3. Configure the Firebase project.
4. Set up the Python Flask backend.
5. Configure the required environment variables.
6. Start the frontend and backend servers.

Note: Detailed installation commands will be added when the application source code is implemented.

## Environment Variables

The following configuration values will be required:

- `FIREBASE_API_KEY`
- `FIREBASE_PROJECT_ID`
- `FIREBASE_AUTH_DOMAIN`
- `BACKEND_URL`

Actual credentials must be stored securely in environment files and must never be uploaded to GitHub.
