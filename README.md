# WAYFORALL
### AI-Powered Accessible Navigation for Wheelchair Users

## About the Project
WAYFORALL is an accessibility-focused navigation platform designed to help wheelchair users travel more independently and safely.

## Problem
Wheelchair users face difficulties navigating public spaces due to broken footpaths, missing ramps, stairs and blocked pathways.

## Our Solution
WAYFORALL provides accessible route planning, personalised navigation and community-based barrier reporting.

## Key Features
- Accessible route planning
- Barrier reporting through photographs
- Personalised accessibility preferences
- Community-verified accessibility information
- Voice navigation

## Technology Stack
- React
- Python Flask
- Firebase
- OpenStreetMap
